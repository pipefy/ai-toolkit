# CLI reference

For investigation calls (`get_pipe`, `get_cards`), use the CLI reference in `pipefy-pipes-and-cards`. For `get_automations`, `get_automation_events`, and `create_automation`, use `pipefy-automations`; for `get_ai_agents`, use `pipefy-ai-agents`. Field-condition creation belongs to `pipefy-pipes-and-cards`. Apply the workflow’s shared arguments through the selected command’s supported options.
