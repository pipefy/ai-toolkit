# Skills rules

Scoped to `skills/`. Before you add or edit a skill, read [`docs/contributing/skills.md`](../docs/contributing/skills.md). It holds every rule for a skill: the steps to add one, the names, the frontmatter, the body style, what CI checks, and the review rubric. The pre-commit hooks enforce the rules a script can check, so stage the skill and run `uvx pre-commit run` before you push.
