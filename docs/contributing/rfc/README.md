# Requests for comments

An RFC proposes a change that needs input from other contributors before anyone decides it. It states a problem, the desired end state, and how to reach it, and it ends with the questions that review must answer. An accepted RFC produces one or more decision records in [`../adr/`](../adr/README.md), and those records hold the decisions from then on.

Each RFC opens with these header lines:

- `Status` is `Draft`, `Accepted`, `Rejected`, or `Withdrawn`.
- `Author` names the person who wrote it.
- `Created` is the date of the first draft.
- `Discussion` links the pull request or issue where review happens.

The title states the end goal, not the means. The means go in the Proposal section.
