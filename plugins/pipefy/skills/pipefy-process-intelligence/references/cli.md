# CLI reference

For `get_pipe`, use the CLI reference in `pipefy-pipes-and-cards`. The recent-card sample is `pipefy card records --pipe <PIPE_ID> --first 50 --include-fields --order-by '[{"attribute": "CREATED_AT", "direction": "DESC"}]' --json`. The timed card read is `pipefy graphql exec -q '<document>' --vars '{"pipeId": "<PIPE_ID>"}' --json` with the TimedCards document in the skill; it is a query, so no `--yes`. For `get_automations`, `get_automation_events`, and `create_automation`, use `pipefy-automations`; for `get_ai_agents` and `get_ai_agent`, use `pipefy-ai-agents`. Field-condition creation belongs to `pipefy-pipes-and-cards`. Apply the workflow’s shared arguments through the selected command’s supported options.
